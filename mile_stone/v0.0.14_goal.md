```text
Natural Language → Semantic Intent → Secure Infrastructure Execution
```

```text
Semantic Infrastructure Runtime
```

# Core Architectural Principle

## LLM은 Command Generator가 아니다

VEGA는 다음 구조를 따른다:

```text
User Input
    ↓
LLM Semantic Parsing
    ↓
Typed Intent Enum
    ↓
Rust Execution Layer
    ↓
Secure Deterministic Execution
```

LLM의 역할:

- 의도 이해
- Semantic Goal 추론
- Intent Classification

LLM이 하지 않는 것:

- Bash 생성
- Raw Command 생성
- Shell Script 작성
- 직접적인 시스템 조작

# Typed Intent Architecture

예시:

```rust
enum OllamaIntent {
    Version,
    ListRunning,
    ListInstalled,
    Pull { model: String },
    Remove { model: String, force: bool },
}
```

LLM 출력:

```json
{
  "action": "OLLAMA_PULL",
  "target": "192.168.0.150",
  "params": {
    "model": "mistral"
  }
}
```

Rust 실행 레이어:

```rust
match intent {
    OllamaIntent::Pull { model } => {
        ssh.exec(format!("ollama pull {}", model));
    }
}
```

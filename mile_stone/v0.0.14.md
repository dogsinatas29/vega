# VEGA Milestone v0.0.14: Hybrid Execution Hardening

## 🎯 Overview
VEGA의 오케스트레이션 레이어를 하이브리드 실행 아키텍처로 고도화하여 로컬과 원격(SSH) 실행의 경계를 명확히 하고, 시스템의 결정론적 동작과 안전성을 확보함.

## 🛠️ Key Transformations

### 1. Hybrid Execution Path (`ExecutionTarget`)
- **Explicit Dispatch**: `ExecutionTarget` 열거형(`Local`, `RemoteSsh`)을 도입하여 실행 대상을 명확히 정의함.
- **Anti-Fallback Enforcement**: SSH 연결 실패 시 `localhost`로 자동 전환되던 hallunication 로직을 제거하여 의도치 않은 로컬 시스템 변경을 방지함.

### 2. Action Trait Hardening
- **Stateless Actions**: `Ollama`, `Docker`, `Apt` 등 모든 액션 구조체에서 연결 정보(`target_host`, `user` 등)를 제거하고 무상태 구조로 전환.
- **Contract-Based Execution**: `Action` 트레이트에 `build_command()`를 추가하여 실행 전략과 액션 정의를 분리하고, 오케스트레이터가 실행을 전담하도록 개선.

### 3. Orchestration Safety Logic
- **Sequential Validation**: 실행 전 스냅샷, 정책 체크, 사용자 확인, 크리티컬 가드(세션 체크 및 쿨다운) 순서를 엄격히 강제함.
- **Atomic Operations**: 보안 검증이 모두 완료된 시점에만 실제 명령어가 디스패치되도록 로직을 재구성함.

### 4. Environment-Aware Cognition & Grounding
- **Target Heuristics**: "ssh에 연결된 시스템", "원격 머신" 등 추상적 지시어를 현재 관리 중인 원격 호스트로 자동 매핑하는 휴리스틱 리졸버 도입.
- **Infrastructure Context Injection**: AI 프롬프트에 [Type, User, IP, Status]를 포함한 상세 인벤토리를 주입하여 LLM의 환경 인지(Awareness) 능력을 극대화함.
- **Isolation Enforcement**: Ollama 명령어에 `OLLAMA_HOST=127.0.0.1:11434` 환경 변수를 강제하여 로컬 및 원격 실행의 격리성과 안정성을 확보함.

### 5. Sovereign Orchestration & Ownership Inversion (v0.0.14.5+)
- **Sovereign Parser**: LLM 호출 전 동작하는 결정론적 파서를 도입하여 100% 신뢰 가능한 명령에 대해 LLM을 완전히 우회(Bypass)하는 Fast-Path 구축.
- **Dual-Core Cognition**: 결정론적 규칙 엔진(Sovereign Core)과 의미적 추론 엔진(Semantic Core)을 결합하여 지연 시간 제로 및 100% 결과 결정론(Output Determinism) 달성.
- **Intent Correcting Firewall**: `IntentValidator`를 통한 의도 모순 탐지 및 자동 교정(e.g., REMOVE -> PULL) 로직 구현으로 할루시네이션에 의한 파괴적 작업 원천 차단.
- **Entity & Slot Locking**: 모델명(Regex), 타겟(IP/Keywords), 동사(Verb Dictionary) 리졸버를 완전히 분리하고 확정된 엔티티를 파이프라인에 고정(Lock)하여 문맥 오염 방지.

### 6. Cognition Hardening & Sovereign Recovery (v0.0.14.10+)
- **Symbolic Target Alias Resolution**: "ssh로 접속한 시스템", "원격 서버" 등 자연어 속 상징적 타겟 포인터를 결정론적으로 추출하여 LLM 실패와 무관하게 타겟을 100% 복구.
- **Tolerant Parser**: LLM의 비표준 JSON 출력(Markdown, Single Quote 등)을 정밀하게 정화하고 유효한 구조로 복구하는 인지 복구 엔진 탑재.
- **Full Slot Rehydration**: LLM 응답 유실 시 원본 쿼리와 Discovery Context를 결합하여 [Target, Model, Action] 슬롯을 결정론적으로 재구성하는 완전 재수화 메커니즘 완성.
- **Exploration Taxonomy & Autonomy**: 탐색형 의도(LIST/DISCOVER)를 전용 액션으로 분류하고, 타겟 필수 검증을 면제하는 '무타겟 자율성(Target-less Autonomy)' 구현.
- **Action Surface Expansion**: `SshListTargetsAction`, `InfraListRemotesAction` 등 탐색형 액션의 실제 구현체를 Action Factory에 연결하여 인지-실행 사이클 완성.

### 8. Structured Event Protocol & High-Fidelity Reporting (v1.1.0 Alpha 26+)
- **JSON Protocol Envelope**: `__VEGA_JSON__{...}` 형태의 머신 가독형 엔벨로프를 도입하여 쉘 노이즈로부터 결정론적 상태 데이터를 격리.
- **Semantic Event Schema**: `SERVICE_READY`, `SERVICE_ERROR` 등 고충실도 이벤트 타입을 통해 단순 성공/실패를 넘어선 의미론적 오케스트레이션 가시성 확보.
- **Rust-Side Event Parser**: stdout 스트림 내에서 JSON 이벤트를 추출하고 분석하는 전용 파서를 탑재하여 프로토콜 무결성 달성.
- **Explanation Layer Consistency**: 인지(Validator)부터 실행(Pipeline)까지 모든 레이어의 설명 로직을 100% 동기화하여 통일된 기술 보고 체계 완성.

### 9. SRE-Grade Verbosity & Narrative UX (v1.1.0 Alpha 40+)
- **Verbosity Profiles**: `Silent`, `Normal`, `Operator`, `Developer`, `Debug` 레벨의 정교한 상세도 프로필을 도입하여 운영자 중심의 정보 제공 체계 구축.
- **Internal Log Suppression**: Discovery, Sovereign Parser, Classifier 등 내부 추론 단계의 로그 노이즈를 Normal 모드에서 완전히 제거하여 내러티브 중심의 UX 달성.
- **SRE Narrative Presentation**: 복잡한 시스템 로그 대신 "Analyzing -> Resolving -> Executing -> Reconciling"으로 이어지는 전문가급 운영 내러티브 제공.
- **State Convergence Branding**: 단순 실행 도구가 아닌, 시스템의 '상태 수렴(State Reconciliation)'을 책임지는 지능형 런타임으로 브랜드 진화.

## 🚨 Security & Stability
- **Active Session Guard**: 원격 시스템에 다른 사용자가 접속 중일 경우 경고를 표시하여 장애 전파 방지.
- **Fail-Closed Target Guard**: 타겟 해석이 불가능할 경우 위험한 기본값(localhost)으로의 낙하를 방지하고 즉시 실행을 중단하는 방어 로직 강화.
- **Action Integrity Firewall**: 최종 실행 직전 액션 유효성을 재검증하여 비어 있는 명령이 전달되는 것을 차단.
- **Deterministic Alias Binding**: 발견된 시스템 자원과 상징적 별칭을 즉시 결합하여 인지 드리프트 원천 차단.
- **Sudo-rs Awareness**: 타겟 시스템의 `sudo-rs` 패키지 특성을 인지하고 비대화형 실행 가능성을 사전 판단.
- **Readiness Timeout Policy**: 서비스별로 최적화된 리트라이 루프와 타임아웃을 적용하여 맹목적 성공(Blind Success) 방지.

# 🚀 Release Notes: v0.0.14-Convergent-Sovereign-Orchestrator

## 🌐 English Summary
VEGA has evolved into an **Autonomous SRE Reconciliation Engine**. This release introduces a professional-grade verbosity abstraction and a self-healing loop that ensures system state convergence through proactive drift detection and automated remediation.

### Key Highlights:
- **Verbosity Abstraction**: Introduced `Silent`, `Normal`, `Operator`, `Developer`, and `Debug` profiles for tailored SRE UX.
- **Autonomous Remediation**: Implemented `OllamaRemediate` for automated process cleanup and state re-convergence.
- **Cognitive Narrative**: Suppressed internal inference noise in normal mode to provide a clean, narrative-driven operator experience.
- **State Proofing**: Enhanced network bind and readiness probing for 100% semantic verification of service health.

---

## 🇰🇷 한국어 요약
VEGA가 **자율 SRE 상태 수렴 엔진**으로 진화했습니다. 이번 릴리즈에서는 전문가급 상세도 추상화와 더불어, 시스템 이격(Drift)을 스스로 감지하고 자동 복구하는 자율 교정 루프를 통해 결정론적 시스템 운영의 기틀을 완성했습니다.

### 주요 변경 사항:
- **상세도 추상화 (Verbosity Abstraction)**: `Silent`부터 `Debug`까지 5단계 상세도 프로필을 도입하여 운영 환경에 최적화된 UX를 제공합니다.
- **자율 교정 루프 (Autonomous Remediation)**: `OllamaRemediate` 액션을 통해 프로세스 교착 상태를 해결하고 목표 상태(Desired State)로 자동 수렴시킵니다.
- **운영 내러티브 최적화**: 일반 모드에서 내부 추론 로그를 억제하여, "분석-해결-실행-수렴"으로 이어지는 정제된 운영 내러티브를 실현했습니다.
- **상태 증명(State Proofing) 강화**: 소켓 바인딩 및 준비도 프로브(Readiness Probe)를 통해 서비스 상태를 의미론적으로 완벽하게 검증합니다.

# VEGA Milestone v0.0.14: Hybrid Execution Hardening

## 🎯 Overview
VEGA의 오케스트레이션 레이어를 하이브리드 실행 아키텍처로 고도화하여 로컬과 원격(SSH) 실행의 경계를 명확히 하고, 시스템의 결정론적 동작과 안전성을 확보함.

## 🛠️ Key Transformations

### 1. Hybrid Execution Path (`ExecutionTarget`)
- **Explicit Dispatch**: `ExecutionTarget` 열거형(`Local`, `RemoteSsh`)을 도입하여 실행 대상을 명확히 정의함.
- **Anti-Fallback Enforcement**: SSH 연결 실패 시 `localhost`로 자동 전환되던 hallunication 로직을 제거하여 의도치 않은 로컬 시스템 변경을 방지함.

### 2. Action Trait Hardening
- **Stateless Actions**: `Ollama`, `Docker`, `Apt` 등 모든 액션 구조체에서 연결 정보(`target_host`, `user` 등)를 제거하고 무상태 구조로 전환.
- **Contract-Based Execution**: `Action` 트레이트에 `build_command()`를 추가하여 실행 전략과 액션 정의를 분리하고, 오케스트레이터가 실행을 전담하도록 개선.

### 3. Orchestration Safety Logic
- **Sequential Validation**: 실행 전 스냅샷, 정책 체크, 사용자 확인, 크리티컬 가드(세션 체크 및 쿨다운) 순서를 엄격히 강제함.
- **Atomic Operations**: 보안 검증이 모두 완료된 시점에만 실제 명령어가 디스패치되도록 로직을 재구성함.

### 4. Environment-Aware Cognition & Grounding
- **Target Heuristics**: "ssh에 연결된 시스템", "원격 머신" 등 추상적 지시어를 현재 관리 중인 원격 호스트로 자동 매핑하는 휴리스틱 리졸버 도입.
- **Infrastructure Context Injection**: AI 프롬프트에 [Type, User, IP, Status]를 포함한 상세 인벤토리를 주입하여 LLM의 환경 인지(Awareness) 능력을 극대화함.
- **Isolation Enforcement**: Ollama 명령어에 `OLLAMA_HOST=127.0.0.1:11434` 환경 변수를 강제하여 로컬 및 원격 실행의 격리성과 안정성을 확보함.

## 🚨 Security & Stability
- **Active Session Guard**: 원격 시스템에 다른 사용자가 접속 중일 경우 경고를 표시하여 장애 전파 방지.
- **Cooldown Period**: `Critical` 등급 액션 실행 전 5초의 대기 시간을 강제하여 사용자 취소 기회 제공.
- **RAW SSH Observability**: 트랜스포트 레이어에서 STDOUT/STDERR/EXIT_CODE를 파싱 전 콘솔에 다이렉트로 노출하는 디버그 블록 주입.

## 🇰🇷 [KOR] Sovereign Remote SRE Control

### 🚀 핵심 업데이트 (Core Updates)
1. **보안 내장 SSH 엔진 (ssh2) 도입**
   - 외부 의존성(`sshpass`) 없이 Rust 네이티브 엔진을 통해 원격 명령을 직접 제어합니다.
   - 비대화형 세션에서의 `sudo` 프롬프트 문제를 완벽히 해결했습니다.

2. **Sudo 자동 암호 주입 (Auto-Sudo)**
   - `KnowledgeBase`에 저장된 암호를 활용하여 `sudo -S` 명령 시 자동으로 암호를 주입합니다.
   - 서비스 정지(`systemctl stop`), 프로세스 종료(`pkill`), 시스템 종료(`shutdown`) 등 권한이 필요한 작업을 사용자 개입 없이 수행합니다.

3. **원샷 원격 진단 (One-Shot Diagnostic)**
   - 10여 개의 개별 SSH 호출을 단일 멀티 커맨드 세션으로 통합하여 수집 속도를 10배 이상 향상시켰습니다.
   - 단 한 번의 접속으로 호스트명, CPU, RAM, 네트워크 상태를 일괄 수집합니다.

4. **정체성 격리 (Zero-Noise Identity)**
   - 원격 진단 중 로컬 노드의 식별 정보가 리포트를 오염시키지 않도록 `Silent Discovery` 모드를 구현했습니다.

## 🇺🇸 [ENG] Sovereign Remote SRE Control

### 🚀 Key Features
1. **Secure Internal SSH Engine (ssh2)**
   - Leverages a native Rust engine for remote execution, eliminating external dependencies like `sshpass`.
   - Resolves TTY-related `sudo` prompt issues in non-interactive sessions.

2. **Automatic Sudo Password Injection**
   - Injects saved passwords from the `KnowledgeBase` into `sudo -S` prompts automatically.
   - Enables seamless privileged operations: stopping services (`systemctl`), killing processes (`pkill`), and performing system shutdowns.

3. **One-Shot Remote Diagnostic**
   - Consolidates 10+ individual SSH calls into a single multi-command payload, increasing collection speed by 10x.
   - Aggregates Hostname, CPU, RAM, and Network metrics in a single session.

4. **Zero-Noise Identity Isolation**
   - Implemented `Silent Discovery` mode to prevent local node identity drift from contaminating remote reports.
